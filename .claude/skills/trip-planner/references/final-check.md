# Final check — run before calling the plan done

Each item below is a mistake that has really happened in a planning session. Go through all of them.

## Dates, hours, closures
- [ ] Every museum/attraction is open on the day it's scheduled (many close Mon/Tue/Wed).
- [ ] Every restaurant is still open (not "permanently closed"); hours cover the planned time.
- [ ] Rainy-day backups are themselves open that day.
- [ ] Holiday/event traffic and airport buffers are accounted for.

## Timeline feasibility
- [ ] Meal times are realistic after schedule shifts (no lunch at 10 am, no dinner before a tour returns).
- [ ] Activities don't overlap (e.g. a "sunset walk" while a tour is still out).
- [ ] Hotel check-in/check-out times fit arrival/departure; bag-hold noted.
- [ ] Rental car pickup/drop-off times fit flights (drop-off ≥ 2.5 h before departure, never after).
- [ ] Ticket vouchers/exchanges have time built in (e.g. exchange 45 min before departure).
- [ ] Drives are on the way; no backtracking between stops.

## Preferences honored
- [ ] Every meal has options for each traveler's diet; no excluded foods as the only choice.
- [ ] Preferences were read correctly (re-read the user's own words for likes vs dislikes).
- [ ] Pace and start times match what they asked for; rest blocks exist.
- [ ] Their collected sources (videos, notes) are reflected, with "From videos" tags.

## Money
- [ ] Prices labeled as estimates unless from the user's checkout.
- [ ] Hidden fees surfaced: resort/destination fees, parking, auto-gratuity, card fees, one-way fees, bag fees, toll plans.
- [ ] Budget total recomputed after every change; trims listed.
- [ ] Add-ons (insurance, protection plans) compared against existing coverage.

## Page & maps
- [ ] Each day's numbered pins match the timeline badges and the Google Maps route order (exclude tour-bus legs from walking routes).
- [ ] Every place has a working 📍 Google Maps link.
- [ ] No console errors; no horizontal scroll at ~390 px; theme as requested.
- [ ] Bookings tracker, to-do checklist and budget agree with each other.
- [ ] No personal data on the page (names, confirmation/ticket/policy numbers, addresses, phone, email).
- [ ] Sources listed with the date checked.
